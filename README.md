# Pipeline-analiz: Applied Bioinformatics & Machine Learning

Bioinformatics quality control, variant calling, and downstream data science pipeline for Next-Generation Sequencing (NGS) data (`SRR24003043`).

---

##  Repository Structure

* **`analiz.py`**: Python script executing automated data inspection, schema formatting, and summary statistics (`pandas`, `numpy`).
* **`varyantlar.csv`**: Parsed variant dataset containing extracted genomic attributes (`POS`, `REF`, `ALT`, `QUAL`).
* **`varyantlar.bcf`**: Binary Call Format (BCF) variant file generated via `bcftools`.
* **`fastp_rapor.html` / `fastp_rapor.json`**: Interactive quality control and adapter-trimming reports produced by `fastp`.
* **`SRR24003043_1_fastqc.html` / `SRR24003043_2_fastqc.html`**: Visual FASTQ quality reports generated by `FastQC`.
* **`.gitignore`**: Excludes high-volume raw sequencing files (`.fastq`, `.sam`, `.bam`) to respect GitHub storage constraints.

---

##  Pipeline Architecture

1. **Quality Control & Preprocessing:** Evaluated raw paired-end reads (`SRR24003043`) with `FastQC` and performed automated adapter trimming and quality filtering using `fastp`.
2. **Genome Alignment:** Mapped clean reads to the *Bacillus subtilis* reference genome (`NC_000964.3`) using `bwa mem` and processed coordinate-sorted alignment files with `samtools`.
3. **Variant Identification:** Computed genotype likelihoods via `bcftools mpileup` and called variants using `bcftools call`.
4. **Downstream Feature Extraction:** Streamed variant records into CSV format (`bcftools query`) for exploratory analysis in `analiz.py` and non-linear regression modeling in AITool.
